
# 实验：Python列表、元组、集合
## 实验目的
1. 掌握列表、元组、集合可变/不可变特性，理解可哈希判定规则。
2. 理解切片删除原理，区分遍历列表删除元素的错误写法与安全写法。
3. 熟练集合交、并、差、对称差运算，掌握集合推导式。
4. 对比无序去重与保序去重的多种实现方式。
5. 完成选课综合案例与嵌套列表去重拓展。

## 运行环境
- Python 3.10+
- 无第三方库依赖
